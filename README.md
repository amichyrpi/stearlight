# Stearlight

The maintained OS target is the **ARM64 Steam Frame test VM** in [vm/](vm/README.md).
Valve's Steam client, SteamVR and Gamescope provide the dashboard, docks and laser.

Download the Windows VM package from [GitHub Actions](https://github.com/amichyrpi/stearlight/actions/workflows/build.yml)
or a tagged [VM release](https://github.com/amichyrpi/stearlight/releases).
Extract the entire ZIP and double-click `start-vm.cmd`.

The original streaming project sources remain at the repository root.
